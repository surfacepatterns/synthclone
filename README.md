`synthclone` is a Qt-based application that can **clone** your MIDI-capable
instruments.  It does this by sending out MIDI data that instructs an
instrument to emit sounds for a series of notes, velocities, control values,
etc.  You can then take that data and export it to a sample-based format that
can be loaded by sampler software.

This branch contains current progress on the `synthclone` rewrite.
